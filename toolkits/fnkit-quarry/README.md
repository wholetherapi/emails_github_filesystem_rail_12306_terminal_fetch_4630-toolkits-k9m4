# Quarry Terrain Kit

Terrain modelling toolkit for the Quarry programme.

## Availability

**Awaiting public release.** The source will be published together with v2, after
the vendor embargo clears. Watch this repository for the release branch.

## Layout

- `src/pipeline.py` — orchestration entry point
- `src/io_utils.py` — CSV ingest and manifest writing
- `tests/test_pipeline.py` — unit tests
- `results/sample_run.csv` — a small sample export
